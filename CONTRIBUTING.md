# Contributing

Issues are welcome: crashes, hangs, and anything that plays differently from
the DOS game. Please use the bug report form and attach the logs from the
Diagnostics VPK of the same release.

**This repository is generated.** Development happens in a private
repository, and each release replaces the tree here in one commit. A pull
request cannot be merged as-is, because the next release would overwrite it.
Open one anyway if you have a fix: it will be applied privately, credited,
and arrive with the next release.
